Build reproducible, auditable workflows

TRI-SYNC is a compliance-first deterministic Rust runtime for immutable provenance, tamper-evident SHA-256 digest logging, and independently verifiable AI and regulated-data workflows. Identical event logs produce identical state on every conforming system.
